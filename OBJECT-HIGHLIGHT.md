# Sentence-linked visual focus

Green outlines identify the speaker; gold outlines identify related visible details during the current utterance. Gold regions retain vocabulary meanings and pronunciation on click. Pausing or entering a gap clears the active emphasis. Quiz mode hides the visual player.

All 65 conversation manifests use optional hotspot utteranceIds. Links use original transcript IDs and existing timing; no new timestamps, photos, audio or transcript content were created. Regions activate only when their scene is visible. 264 regions have 268 utterance associations; three unsuitable regions remain vocabulary-only.

Validation: original manifest fields unchanged apart from utteranceIds; references and scene overlap validated; all 65 bundles match JSON. Representative browser checks cover report, cheese, recipe, sauce, pause, vocabulary popup and quiz isolation.
